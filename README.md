# Frontend UI Clones

A set of static user interface clones of popular websites built to practice responsive CSS layout structures, typography matching, and pixel-perfect design replication.

## Tech Stack
* HTML5
* CSS3 (Custom Flexbox and Grid, CSS variables)

## How to Run
Serve the directory with a local HTTP server and open the target HTML pages in a browser.

Example:
```bash
python -m http.server 8000
```
Then open http://localhost:8000/website.html or http://localhost:8000/facebook.html in your browser.
